# Reusable Repository Execution Prompt

Read repository instructions and inspect exact Git state. Identify objective, current implementation, root cause, dependencies, security/deployment impact and missing validation. Prioritize P0/P1/P2/P3. Implement the smallest safe change, preserve unrelated work, add regression coverage, validate, and report baseline, files, evidence, failures, unresolved risks and next safest action. Anything not executed is `UNVERIFIED`.
